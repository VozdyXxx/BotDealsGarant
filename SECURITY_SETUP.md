# 🔒 Repository Security Setup

## Автоматическая защита настроена через GitHub Actions!

### ✅ Что уже работает:
- 🚫 Автоматическое закрытие Issues от неавторизованных пользователей
- 🔒 Блокировка неавторизованных Pull Requests
- 📧 Перенаправление пользователей на прямые контакты
- 🛡️ Автоматическое уведомление администратора

### 🔧 Дополнительные настройки через веб-интерфейс GitHub:

1. **Отключить Issues полностью:**
   - Перейти в Settings → General → Features
   - Убрать галочку с "Issues"

2. **Ограничить Pull Requests:**
   - Settings → General → Pull Requests
   - Включить "Restrict pushes that create files"

3. **Настроить Branch Protection:**
   - Settings → Branches → Add rule для "main"
   - Включить "Require pull request reviews"
   - Включить "Dismiss stale reviews"

4. **Настроить Collaborators:**
   - Settings → Manage access
   - Добавить только доверенных пользователей
