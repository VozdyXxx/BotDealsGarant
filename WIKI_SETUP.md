# 📚 GitHub Wiki Setup Instructions

Этот файл содержит инструкции по настройке Wiki для репозитория BotDealsGarant.

## 🔧 Настройка Wiki в GitHub

### 1. Включить Wiki в настройках репозитория:
1. Перейдите в настройки репозитория: https://github.com/VozdyXxx/BotDealsGarant/settings
2. Прокрутите вниз до раздела "Features"
3. Установите галочку напротив "Wikis"
4. Нажмите "Save changes"

### 2. Создать страницы Wiki:
1. Перейдите на вкладку Wiki: https://github.com/VozdyXxx/BotDealsGarant/wiki
2. Нажмите "Create the first page"
3. Скопируйте содержимое из файлов в папке `wiki/`

## 📄 Страницы для создания:

### Home (Главная страница)
- Скопировать содержимое из `wiki/Home.md`
- Это будет главная страница Wiki

### Getting Started
- Создать новую страницу "Getting-Started"
- Скопировать содержимое из `wiki/Getting-Started.md`

### Roadmap
- Создать новую страницу "Roadmap"  
- Скопировать содержимое из `wiki/Roadmap.md`

## 🚀 Автоматическая настройка

После создания Wiki вы можете:

1. **Включить Issues:**
   - В настройках репозитория включить "Issues"
   - Шаблоны уже созданы в `.github/ISSUE_TEMPLATE/`

2. **Проверить ссылки:**
   - Bug Reports: https://github.com/VozdyXxx/BotDealsGarant/issues/new
   - Feature Requests: https://github.com/VozdyXxx/BotDealsGarant/issues/new?labels=enhancement&template=feature_request.md
   - Wiki: https://github.com/VozdyXxx/BotDealsGarant/wiki

## ✅ Проверка

После настройки убедитесь что:
- [ ] Wiki включено в настройках
- [ ] Issues включено в настройках  
- [ ] Создана главная страница Wiki
- [ ] Ссылки в README работают корректно
